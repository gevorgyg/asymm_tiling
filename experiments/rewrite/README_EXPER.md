# Presentation claims: rewrite vs pre-rewrite simulator

Each row is a slide claim, re-run with the rewritten simulator on the same
setup as the original experiment. The details are in `out/<name>/README.md`,
and each is regenerated by `.venv/bin/python experiments/rewrite/<name>.py`.

Why cycle counts differ by design (details in `old_results.py`): the old
simulator charged cache latency per element, the rewrite per line, so
L1-resident work is about 4× cheaper while a memory miss still costs 180
cycles. alpha therefore shrinks by 2–4×, and every gc threshold, which
scales with alpha × TM, moves down. Cache traffic is the like-for-like check.
