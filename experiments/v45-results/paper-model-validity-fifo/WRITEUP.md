# paper-model-validity-fifo — Writeup

The dense-times-random reading of the asymmetric-cost papers: B is not stored
but **recomputed on the fly** (a random projection). Here B is generated by
the PRNG-FIFO device from a small per-tile seed, and we ask the same
model-validity question as the mem experiment — how far can the C tile grow
relative to L1 before a real cache stops behaving like the paper's idealized
fast memory — but now with generation instead of fetch as B's cost.

## Cost parity (the point of the setup)

For the comparison to be meaningful, one A element fetched from DRAM must cost
the same as one B element generated:

- A per element from DRAM: `MEM_ACCESS_CYCLES / (line / precision)`
  `= 160 / (64 / 8) = 20` cycles.
- B per element from the FIFO: `PRNG_FIFO_GEN_COST = 20` cycles.

A and B share 8 B precision, so ρ = 1 — this isolates the *stationarity /
recompute* effect from the mixed-precision effect. Seed = 8 B per B tile.

## Setup

m = 128, n = 512, k = 64, TILE_K = k, C-stationary, `--Bsource prng_fifo`.
Aspect fixed at 4; tiles (4×16 … 128×512) sweep the C-tile budget so
`log₂(C-tile / 4 K L1)` runs -3..7. Regimes: fully-associative (reference)
and 8-way.

## Plots and what to look for

- **six metric views** vs budget — cycles now include B generation; the grey
  vertical marks C-tile = L1 (budget 0), the point past which C cannot stay
  resident.
- **assoc_excess** = 8-way L1 traffic / fully-assoc L1 traffic; grey line at 1
  means associativity is free. Rising above 1 as the tile grows is the
  conflict-miss penalty a real cache pays that the paper's model cannot see.
- **fifo_generations** — B elements generated vs budget. Under C-stationary
  the C tile is held but B is *not*, so B is regenerated on every pass; expect
  a high, roughly work-proportional generation count. This is the number the
  B-stationary companion is designed to cut.
