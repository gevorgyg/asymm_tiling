This is a project meant to simulate computer architecture for matrix tiling
where matrices have asymmetric access costs -- one (A) is in memory and another
(B) is generated by a prng device.

Read README.md for more details.

There are some anti-patterns you should avoid:

- DO NOT add trivial types, e.g. do not do:
    using Cycles = unsigned int;
    <...>
    Cycles cycles;
    <...>

    Strive to express your intent in the name of the variable.
